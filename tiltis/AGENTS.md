# PAC 2026 공동 작업 지침

- 먼저 `COLLABORATION.md`, 양쪽 `HANDOFF.md`, 관련 코드와 최근 Git 변경을 읽는다. 현재 사용자 요청을 우선한다.
- Codex의 기본 작업 위치는 `codex/`, Claude Code의 기본 작업 위치는 `claude-code/`다. 상대 구현을 재사용하거나 수정할 수 있다. 중복 구현 전에 기존 SDK·IK·단위·정지 계약을 확인한다.
- 상대 코드를 수정할 때 문제의 재현 조건, 수정 근거, 검증 결과를 기록한다. 기존 변경을 덮어쓰거나 실행 중인 배포본을 자동 교체하지 않는다.
- 완료 시 자기 `HANDOFF.md`에 변경 파일, 테스트 명령·결과, 미검증 사항, 다음 연결부와 상대 검토 결과를 갱신한다. 실행하지 않은 테스트나 하드웨어 동작을 완료했다고 쓰지 않는다.
- 검사는 `claude-code/PAC2026_system`, 손목 제어는 `codex/pac_minimal`에서 독립 실행한다. 공통 필요가 확인된 SDK·URDF·통신 계약만 근거를 갖고 재사용한다.
- Python 3.10 비전 환경과 LeRobot Python 3.12+ 환경을 분리한다. 가상환경·영상·로그·DB·비밀값은 커밋하지 않는다.
- 실제 로봇은 모델·SDK·보정·축·단위·현재 EE·관절 한계·충돌·실제 속도/정지 수단 확인 후, 사용자의 실기 승인 뒤 저속으로 움직인다. 모의 작업 범위를 실기에 적용하지 않는다.
- Git 쓰기는 현재 사용자 승인 범위에서 수행한다. 공유 브랜치에서 강제 push/reset을 하지 않고, 원격 변경이 있으면 확인 후 통합한다.
