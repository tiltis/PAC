# 70mm 정육면체 가상 깊이 시험 (2026-10-08, 노트북)

설치 가정: Gemini 2 책상 위 190mm, 14° 아래(현재 설치). locate_mode front, box_mm 70×70×70, tab 0. 가상 영상(광선 추적 + 1.5mm 잡음).
실제 카메라로는 아직 확인하지 않음.

| 조건 | 결과 |
|---|---|
| 거리 250~500mm × 좌우 −120/0/+120mm × 회전 0/15/30/45° (72가지) | 72/72 찾음, 윗면 중심 오차 중앙값 0.4mm, 최대 1.3mm |
| 실제 상자가 설정(70)과 다를 때, 65 또는 75mm | 찾음, 중심 오차 약 5.5mm |
| 실제 상자 60 또는 80mm | 찾음, 중심 오차 약 11mm (비전 집기 허용 한계 근처) |
| top 모드(윗면 직접) | 찾음, 윗면 변이 74~77mm로 약간 크게 나옴, 중심 오차 1mm 이내 |

결론: **상자 변 길이를 자로 재서 box_mm에 ±2mm 안으로 적을 것.** 5mm 틀리면 집는 점이 5mm 밀린다.
스크립트: 세션 스크래치 cube_sweep.py (sensor/tests/test_locate.py의 70mm 사례가 대표 1건을 테스트로 고정).
