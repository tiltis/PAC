# 10/9 현장 순서 (노트북 터미널, 전부 C:\PAC2026_system)

노트북 전원 연결. Windows 카메라 앱·capture_app 끄기. OneDrive 폴더에서 실행 금지.

## 0. 배치(가르치기 전에 고정)
- 로봇 바닥 중심에서 약 20cm 앞에 7cm 상자. 카메라 3대·파랑 영역(정상)·빨강 영역(불량·확인 필요) 위치 확정. 이후 옮기면 자세 전부 다시. 아래 거리는 예시이며 현장 도달 범위·충돌 확인 후 정한다.
- 상자 두 종류(흰 70×70×90, 갈색 80×80×45)는 설정 완료. 다른 상자가 오면 `sensor\calib\object_config.json`의 `boxes_mm`에 추가.
- 깊이 카메라 앞 집기 영역에는 검사할 상자 하나만(컵·다른 상자 치우기).
- 깊이 카메라는 상자에서 **30~50cm** 떨어뜨려 세운다. 20cm 안쪽이면 흰 상자가 깊이 화면에서 검은 구멍으로 빠져 못 찾는다(10-08 실측).
- RGB 렌즈 앞 가리는 것 없는지 `check_cameras.bat --depth` 샘플(`sensor\check_out\vis.png`)로 확인.

## 1. 포트 찾기
```
.venv-station\Scripts\lerobot-find-port
```
USB를 뺐다 꽂으며 안내대로. 아래 COM5는 예시.

## 2. 보정(1회)
```
.venv-station\Scripts\lerobot-calibrate --robot.type=so101_follower --robot.port=COM5 --robot.id=so101_follower
```

## 3. (선택) 계산 좌표 확인 — 비전 집기 쓸 때만
```
.venv-station\Scripts\python station\teach.py --port COM5 --fk-check
```
집게 끝을 자로 잰 책상 위 3점에 대고 비교. 10mm 넘게 틀리면 `station\calib\joint_map.json`.

## 4. 자세 가르치기
```
.venv-station\Scripts\python station\teach.py --port COM5
```
토크 OFF → 팔을 손으로 옮기고 이름 + Enter. 한 손으로 팔 받치기.

| 이름 | 위치 |
|---|---|
| home | 아무 데도 안 닿는 대기 |
| pick_approach | 상자 위 3~5cm, 집게 수직 아래 |
| pick | 집게가 상자 옆면을 감싸는 높이(흰 상자 윗면에서 약 3.5cm, 갈색 약 2cm 아래) |
| lift | 들어 올림(상자 바닥 5cm 이상) |
| face_A | RGB·열화상 카메라 정면에 옆면 1 |
| face_B | 손목 돌려 옆면 2 |
| face_C | 손목을 더 돌려 옆면 3 (3면 검사용, `-Faces A,B,C`) |
| bin_ok | 파랑 영역에서 상자를 내려놓을 자세(정상) |
| bin_human | 빨강 영역에서 상자를 내려놓을 자세(불량·확인 필요) |
| gripper_open | 9.5cm 이상 벌림(갈색 80mm+여유. 45°=78mm는 부족) |
| gripper_closed | 빈손으로 끝까지 닫음 |
| gripper_held | 상자 물린 채 닫음 |

테이프·검은 기준 패치는 집게에 안 가리는 면(face_A/B가 보여 주는 면)에.

## 5. 재생 확인
```
.venv-station\Scripts\python station\teach.py --port COM5 --replay
```
이동마다 Enter. 부딪히면 그 자세만 4번에서 다시.

## 6. 실행
```
run_all.bat -Depth -Robot so101 -RobotPort COM5 -Faces A,B,C
```
(`-Faces A,B,C` = 3면 검사. face_C 자세가 없으면 빼고 A,B로)
휴대폰(같은 Wi-Fi/핫스팟) → http://<노트북IP>:8000 → 시료 ID → 검사 시작. 방화벽 묻으면 "개인 네트워크 허용".
- 1회차 상자 없이: `집기 실패(pick): nothing_held`로 멈춰야 정상.
- 2회차 상자 넣고: 끝까지 가서 빨강 영역(규칙 없으니 review). 정상 검사 근거가 모두 갖춰지고 모든 면이 no_anomaly일 때만 파랑 영역.

## 7. 검사 규칙(로봇이 된 뒤)
1. 초록 테이프 상자를 면 A 자세로 촬영(면 B·C도 같은 방법, `--face B`, `--face C`) → `python sensor\rules_calib.py roi-tape --capture <폴더> --face A --auto --count <보이는 테이프 수>` → `rules_tape_rois.jpg` 확인. 면 B도.
   테이프 있음 3회 + 없음(떼거나 없는 면) 3회 촬영 → `fit --tape-on ... --tape-off ...` → validated true → 테이프 하나씩 떼며 "테이프 2/3 (누락 T2)" 뜨는지 확인
2. 냉매: 아이스팩 넣고 몇 분 뒤 기준 패치와 촬영 → `roi-coolant` → `fit`(있음·없음 각 3장 이상) → 다른 세션으로 `eval`
3. timing → 규칙 validated:true → `-SingleSpecimen`으로 정상 판정 허용

## 8. (선택) 비전 집기
센서 켠 채 `teach.py --port COM5 --handeye --sensor-url http://127.0.0.1:8001` 상자 6곳 → RMS ≤ 10mm일 때만 저장
→ `run_all.bat -Depth -Robot so101 -RobotPort COM5 -PickMode vision -DryRun` 접근 위치 눈 확인(15mm 이상 어긋나면 중단) → `-DryRun` 빼고 실행.
실패하면 6번(가르친 자세)으로 시연.

## 상자 못 찾을 때(비전 집기)
- `http://127.0.0.1:8001/object/locate?save_debug=1` 결과의 `candidates`·`rejected` 보기. 높이가 안 맞으면 `boxes_mm`, 뒤 물체가 붙으면 `near_far_mm`(object_config.json) 조정.
- 실시간 3화면: `live_view.bat`(서버 켠 채로 됨)

## 멈췄을 때
- 소프트 중단: 웹 "중단". 비상: 로봇 전원 스위치.
- 서버를 강제 종료하면 FLIR가 수동 FFC로 남음 → 다음 실행 때 자동 복구됨.
- 카메라 "이름의 장치가 2개": `set PAC2026_VIS_NAME=<이름>` 후 실행.
